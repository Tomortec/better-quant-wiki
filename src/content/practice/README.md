# 出题规范

这次和以后往题库加题，都按这份说明。审查 PR 也按它打回。引擎逻辑不要再另立一套规则。

词条是检索，题目是检验。不要把 `definition` 原句改写成「下列哪项正确」。

## 测什么、不测什么

测从业者会用错的东西：

- 定义边界（后验 ≠ 似然，相关 ≠ 独立）
- 公式口径（年化、复利、对数收益 vs 简单收益）
- 回测谎言（前视、无限卖空、过拟合）
- 易混词（贴现窗口 vs DCF 贴现率，Held order vs 时效指令）

不测：

- 百科常识、名人名言
- 与交易决策无关的制度史细节
- 站点里已经用派生题覆盖的纯中英识记

与笔记、词条、勘误矛盾时，**先改内容再出题**，不要在题目里另立一套说法。

## 手写还是派生

`src/content/practice/index.ts` 会从 **core** 词条自动生成：

- 单词题 `term:{slug}:en`：看英文写中文
- 单词题 `term:{slug}:definition`：看定义写术语
- 连线题 `match:{chapter}:{sectionId}:zh-en`：该节 core 术语中英配对（至少 4 个才生成）

这些 id 必须保持稳定，进度按 id 存在浏览器里。

**不要手写**与上面重复的纯识记单选。

**必须手写**：计算、情景决策、`caveat` / 勘误陷阱、定制连线（公式↔含义、场景↔工具）。

## 放哪、字段怎么填

一章一个文件：`src/content/practice/{chapterId}.ts`，导出 `Question[]`。

| 字段 | 规则 |
| --- | --- |
| `id` | `{chapter}-{slug}-{nnn}`，如 `probability-bayes-001`。**永不复用、不改已发布 id** |
| `chapter` | 与文件名、九章 id 一致 |
| `conceptSlugs` | 至少一个真实词条 slug |
| `difficulty` | `1` 识记 · `2` 应用 · `3` 陷阱 |
| `kind` | `single` / `multi` / `truefalse` / `match` / `term` |
| `stem` | 题干，中文；关键术语可括注英文；公式用 `$...$` |
| `explanation` | 详解：先说为何正确，再点破错项 |
| `sectionId` | 建议填，对应 `chapters.ts` 里的节 |
| `skill` | 建议填：`recall` / `calculation` / `trap` |

加完后跑 `npm run typecheck`。模块加载时会校验：id 唯一、slug/section 存在、选项与答案闭合、连线是双射。

## 难度与题型

- **L1 识记**：默认交给派生题。手写 L1 只用于派生盖不住的（例如公式对号）。
- **L2 应用**：从词条 `why` 和笔记情景来——给数字算、给回测设定问下一步。
- **L3 陷阱**：只从 `caveat`、`src/content/corrections.ts`、笔记里点名的易混点出题。
- **计算题**：仍用单选/判断。选项做成易错结果（年化用错 `√252`、复利/单利、对数/简单收益、单位差 100 倍）。详解写出步骤。
- **多选**：仅当「必须同时成立」才用；正确项 2–3 个，错误项也要像那么回事。
- **判断**：禁止咬文嚼字。错句必须是业界真会犯的错，不是换个副词。
- **连线**：4–6 对，同一语义场；干扰来自 `related` 近邻，不要跨章硬凑。

## 干扰项与详解

每个错误选项对应一种真实混淆。禁止明显搞笑项和「以上都是」。

详解结构：

1. 为何正确（计算题写出步骤）
2. 主要错项为什么像、为什么错
3. `conceptSlugs` 里的词条即交卷页的回链，不必在正文再贴 URL

对错都展示详解。

## 一章写多少

- 该章每个 **core** 概念：派生单词题自动有；另应有至少一道 L2 或 L3 手写题（一道题可覆盖多个 slug）。
- 第一期目标：每章 8–15 道手写题。概率、统计、定价、衍生品优先写满。
- `supporting` / `context` 一般不出手写题，除非它是某个 core 陷阱的干扰项。

## 反模式（审查时直接打回）

- 把定义抄进题干再问「这是什么」
- 题干已泄漏答案，或正确项明显更长
- 数字题不写清单位、频率、年化口径
- 改已有题目的 `id`，或删除用户可能已在本地 SRS 里的 id 而不留下兼容说明
- 题目依赖站点未收录的概念，却不先补词条

## 样例

合格 L2（计算，写在 `statistics.ts`）：

> 一个策略样本内年化夏普为 2，独立样本约 3 年。用 $t \approx \mathrm{Sharpe}\times\sqrt{T}$ 粗算，t 统计量最接近？
> 选项含 $2\sqrt{3}\approx 3.5$、误用 $\sqrt{252}$、把 $T$ 当成 3×252 日却仍用年化夏普，以及把夏普本身当成 t。

合格 L3（陷阱，写在 `pricing.ts`）：

> 「β = 1 的股票不增加任何风险。」这个判断对吗？
> 错。β = 1 带入与市场相同的系统风险；原文这句话是勘误，不是定义题。

不合格：

> 条件概率的定义是「在已知 B 发生时 A 的概率，记为 P(A|B)」。下列哪项正确？
> （把 `definition` 抄进题干再让人点原句。）
