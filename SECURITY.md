# Security Policy

## Supported versions

Only the default branch (`main`) is supported.

## Reporting a vulnerability

Please **do not** open a public issue for security problems in the site or the supply chain (dependencies, CI, leaked secrets).

Use [GitHub private vulnerability reporting](https://github.com/Tomortec/better-quant-wiki/security/advisories/new) if it is available, or email the maintainer listed on the GitHub profile.

You should hear back within a week. If we confirm the issue, we will patch `main` and credit you unless you ask otherwise.

Content mistakes (wrong formula, bad translation, mis-tagged term) are **not** security issues — file a normal issue with the content template.
